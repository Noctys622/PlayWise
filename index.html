Administration

PlayWise Admin

Cet espace est affiché uniquement si ton compte Discord est propriétaire du serveur ou possède la permission Administrateur.

Les modifications d’interface sont enregistrées sur ce navigateur. Une base de données pourra ensuite permettre une publication globale.

Pour activer l’envoi, ajoute la variable DISCORD_WEBHOOK_URL dans Vercel. Aucun token de bot ne doit être mis dans le code.
